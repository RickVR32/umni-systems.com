FAQ
How is MFE / MAE measured?

ALRT tracks the best and worst price while each trade is open, so you see how far it really went, not just where it closed.

Do I need NTFY as well?

No. ALRT includes everything NTFY does, with far more detail.

How do I install it?

Buy or rent it on the MQL5 Market, then install it from the Market tab inside MetaTrader. Allow WebRequest for https://api.telegram.org under Tools > Options > Expert Advisors, attach it to a chart and enter your Telegram bot token and chat ID.

Which brokers does it work with?

Any broker that offers MetaTrader 4 or MetaTrader 5. Every UMNi tool ships for both platforms.
